Règles de confidentialité — n8n-smm

Mise à jour : 11 novembre 2026

n8n-smm est une application personnelle utilisée uniquement par son propriétaire, Sylvain Moal.

  • L'application accède à la boîte Gmail de son propriétaire, avec son accord, pour lire et traiter ses propres messages (par exemple des relevés de compte) et, si besoin, lui envoyer des e-mails.
  • Les données restent sur le serveur privé du propriétaire. Elles ne sont ni vendues, ni partagées, ni transmises à des tiers, ni utilisées à des fins publicitaires.
  • L'utilisation des données obtenues via les API Google respecte la Google API Services User Data Policy, y compris les exigences d'utilisation limitée (Limited Use).
  • L'accès peut être retiré à tout moment depuis myaccount.google.com/permissions.

English summary. n8n-smm is a personal tool used only by its owner. It accesses the owner's own Gmail account to process the owner's own messages. Data stays on the owner's private server and is never sold, shared or transferred to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
